# Greylock Labs

digital tools made with love 🩷

We provide elegant free and open source apps for those who feel forgotten by a world drowning in
subscription fees, AI features you never asked for, and needless complexity.

| App | | |
| --- | --- | --- |
| [Callie](https://github.com/greylocklabs/callie) | the missing linux calendar | [callieapp.org](https://callieapp.org) |
| [Jot](https://github.com/greylocklabs/jot) | notes and tasks for the professional writer | [jotwriter.org](https://jotwriter.org) |
| [Woodshed](https://github.com/greylocklabs/woodshed) | the "everything app" for jazz musicians | [woodshedapp.org](https://woodshedapp.org) |

Questions and ideas go to [Discussions](https://github.com/greylocklabs/discussions/discussions),
and bugs to each app's issues. Made in Brooklyn by [Lara Kelley](https://larakelley.com);
[support our work on Ko-fi](https://ko-fi.com/sayonara_lara).
