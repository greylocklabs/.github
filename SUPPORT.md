# Getting help

- Questions, ideas and show-and-tell: [Greylock Labs Discussions](https://github.com/greylocklabs/discussions/discussions).
- Something broken: open an issue in the app's own repository, with its version and how you
  installed it.
- A security problem: please report it privately, as [SECURITY.md](SECURITY.md) describes.

Greylock Labs is one person, so replies can take a few days.
